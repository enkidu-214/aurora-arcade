# 微光游乐场 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在当前目录交付可安装的俄罗斯方块安卓应用，完整传统规则、准确回退、流畅触控与精细动画。
**Architecture:** 独立纯 Kotlin 游戏引擎，Compose 管理页面，Canvas 渲染棋盘；输入和逻辑即刻生效，视觉过渡独立。
**Tech Stack:** Kotlin2.1.20, Compose BOM2025.04.01, AGP8.9.2, Gradle8.11.1, JUnit4。
**Spec:** docs/superpowers/specs/2026-10-03-orbit-design.md

## Global Constraints
- 最低 Android 8 / API26，compile/target35；纯离线，无账号或联网权限。
- 直接在当前文件夹执行，用户已授权执行，不追加阶段审批。
- 动画不得阻塞输入；时光模式保留单步硬降回退，经典模式禁止回退。

## Review Focus
- 新块生成失败后仍能撤回最后硬降。
- 软降、Hold、重复回退不能刷分、复制或重抽方块。
- 暂停、后台、对话框与触摸取消不会残留按键或累积重力。
- 消行/硬降/回退特效快速交错不显示旧棋盘、不阻塞新操作。
- 小屏、系统导航条、超大字体不遮挡按钮。
