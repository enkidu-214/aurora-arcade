## 安卓运行验证

设备：本项目单独创建的 Android 11 / API 30 ARM64 模拟器；Apple M4 Pro，Hypervisor.Framework，宿主 GPU 渲染。

- 安装、启动、首页、设置、帮助、继续游戏、暂停与重新开始可用。
- 按住左右 / 软降、旋转、快速落底、暂存和撤回可操作。
- 四行消除场景：初始 500 分 / 9 行，硬降后 1332 分 / 13 行；撤回后恢复为 500 分 / 9 行，原来的 36 个固定方格恢复，I 块返回顶部中央、初始朝向，出块顺序恢复。
- 优化版本执行 20 次落底 / 撤回循环后，棋盘和分数保持正确，没有 AndroidRuntime 崩溃。撤回只保存一层；再次撤回无效，更早的方块保持不变。
- 展开并收起通知栏，游戏自动暂停，等待手动继续；失焦会清空持续按键。
- 常规屏幕：1080 × 2160 / 420 dpi。小屏与大字体：720 × 1280 / 360 dpi、系统字体 1.3 倍。游戏操作区、侧栏统计与设置可访问；小屏侧栏已改为紧凑排版，设置页可滚动。
- 本地存档实际读回验证了分数、行数、棋盘、当前块、下一个队列与撤回次数。

模拟器中的实际操作视频：`docs/gameplay.mp4`；界面截图：`docs/screenshots/`。

## 流畅度与验证边界

以下帧耗时来自首版优化安装包的历史测量，后续外观调整未重新采集帧率。

逻辑与绘制分离，输入立即生效；绘制跟随 Compose 帧时钟。位移、旋转、落底光轨、消行碎片与向上撤回各自使用短动画，快速输入可结束过期消行效果，动画不阻止操作。

优化版本在宿主 GPU 模拟器中采集了 2324 帧，约 39.5 秒；`gfxinfo` 端到端帧耗时 P50 为 19 ms、P95 为 21 ms，GPU P95 约 4–5 ms。该模拟器的旧版 jank 指标为 98.75%，同时记录 3 次 Frame deadline missed；两种指标不能混为一谈。进一步检查 123 帧明细，交换缓冲到完成的等待中位数约 14.8 ms，而动画阶段中位数约 0.34 ms，说明模拟显示链路显著影响了测量。

以上只能说明模拟器运行和交互已验证，不能宣称在真实手机上达到稳定 60 / 90 / 120 fps。尚未在实体 Android 手机、多刷新率屏幕、最低 API 26 或 Android 15/16 上实测，也未进行商店发布验证。

## 独立代码审查

完成一次独立审查，并修复全部 4 项 P2 发现：

1. 最高分排除仍可撤回的最后一次落子，避免撤回前提前记分。
2. 存档由进程级单一队列排序，避免 Activity 重建后的多个写入器覆盖新状态。
3. 窗口失焦时清空按键并暂停，避免持续移动残留。
4. 设置页面支持滚动，适配小屏和大字体。

相关核心回归测试已纳入 24 项测试；生命周期和布局修正在模拟器复核。
