# Release 0.1

微光游乐场的首个发布版本，包含离线俄罗斯方块。

- 传统 10 × 20 棋盘、七袋随机出块、SRS 双向旋转、暂存、落点预览和自动加速。
- 时光模式支持把刚刚快速落底的一块撤回顶部，恢复该次落子的棋盘与得分；只保留一次撤回机会。另有经典模式。
- 沉浸式大棋盘、顶部两个后续预览、68 dp 主操作键；回顶部和落底位于右侧。
- 无花纹七色方块、柔和深蓝灰背景、不带表情的像素箭头，以及位移、旋转、消行和撤回动画。
- 按下立即响应，长按连续移动；可调整操控速度、音效、振动及动态效果。
- 自动保存对局；失去焦点或切到后台会暂停。
- Android 16（API 36）编译与目标 SDK，最低 Android 8.0（API 26）。

下载 `aurora-arcade-0.1.apk` 安装；`SHA256SUMS` 用于验证下载文件完整性。无需网络权限、账号或登录。

此版本启用独立发布签名。如果安装过早期本地测试 APK，需要先卸载测试包，卸载会清除原有对局和记录；之后的发布版本使用同一签名覆盖升级。

测试设备、操作结果与帧数据见仓库中的 [0.1 验证记录](https://github.com/enkidu-214/aurora-arcade/blob/v0.1/docs/release-0.1-verification.md)。模拟器测试不等同于所有实体手机上的帧率保证。
