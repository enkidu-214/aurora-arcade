# 超新星弹球 0.4 验证记录

日期：2026-10-04。版本：0.4 / versionCode 5。保留 0.3 的九款游戏，新增原创「超新星弹球」。

## 已实现

固定透视球台、金属球与阴影、两条有高度的回旋轨道、三枚弹射器、三枚独立靶标、反应核心、侧面弹弓、双挡板、蓄力与技巧开球、三次机会、八秒救球、三秒冷却震台、连击和倍率、四阶段任务链、核心战与下一星区。

击球充满能量后手动触发三球超新星，持续二十秒双倍奖励，包含碰撞、连击和任务奖励。超新星期间轨道和核心提供大奖；增益结束后仍存活的球继续留在场上。只有最后一颗球落下且没有救球保护时才扣一次机会。

原生多指输入在 DOWN 时响应，左右挡板独立；物理每秒 240 个固定步长，帧时钟保留不足一毫秒的余数。几何在 Canvas 缓存，HUD 每 100 ms 更新，存档按事件、两秒间隔、暂停与离开触发。无新运行时依赖或网络权限。

## 安卓 16 设备验证

Android 16 / API 36 ARM64 模拟器，1080×2160、420 dpi，已签名 Release APK。未使用 debug 专属规则或生产环境测试后门。

- 注入真实 Android 多触点事件：两个挡板同时抬起；松开左指后右挡板保持；全部松开后回落。截图为 `both-flippers.png`、`right-flipper.png`、`released.png`。
- 从实际物理模拟产生的能量满存档进入游戏，点击超新星：三球出现、双倍计时和救球计时启动。暂停后的完整存档在等待与进程重启期间逐字一致；重新进入后仍是原来的三球、分数和倒计时。
- 核心任务存档显示「击破反应核心」、0/5 进度，目标高亮正确。
- 蓄力过程中展开通知栏，返回后自动保持暂停，存档中蓄力归零且未误发射。实际按住 850 ms 后松手开球，获得 2,500 分技巧奖励。
- 重开后 0.2 秒强制结束进程，仍保存为 0 分、三次机会、等待开球；旧局没有覆盖新档。崩溃缓冲区为空。
- 原俄罗斯方块首页入口、继续上次到实际棋盘、暂停均通过；其规则回归测试保持通过。
- 320dp 逻辑宽度、1.3 倍字体下，左右挡板、超新星、震台与暂停均可见；玩法长文可滚动，确认按钮可达。检查后恢复 420 dpi / 1.0 倍字体。

持续 61.97 秒进行 270 次挡板操作，并间歇点击超新星及震台，三球始终在场，分数由 13,150 增至 748,150，任务从弹射器推进至靶标 2/3。包含暂停窗口的完整样本共 3,744 帧：现代 Android jank 指标 1 帧（0.03%），P50 / P95 / P99 总帧耗时 17 / 18 / 21 ms，慢 UI 线程计数为 0。游戏主窗口本身记录 3,742 帧、0 jank；另外两帧属于暂停窗口。

原始数据：[android16-0.4-pinball-gfxinfo.txt](metrics/android16-0.4-pinball-gfxinfo.txt)。这些数据反映该模拟器的渲染表现，不是所有手机的帧率保证，也不是端到端触控延迟测量。
