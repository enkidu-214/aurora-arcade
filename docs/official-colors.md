实现使用原生 Canvas / Compose 渐变：去除全部花纹，中心与明暗色来自上述采样；保留小幅倒角和边缘高光。背景重绘为适合竖屏的银灰底色、银框与黑底灰网格，未复制横屏背景中的图案、字样及布局。因此整体色系和取样色一致，不是官网图片的逐像素复制。操作按钮仍使用此前用户要求的圆形 / 胶囊和无表情像素箭头。


后续用户要求降低白色背景亮度、统一整体配色。当前版本外围改为 #263540–#324554 深蓝灰渐变，边框改为 #435664–#627A89，主按钮改为 #96ADBB。上表方块配色和黑底灰网格保持不变；银灰背景的取样值仅记录上一版参考来源，已不用于当前游戏外围。
