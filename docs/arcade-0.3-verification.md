# 九游戏版本 0.3 验证记录

日期：2026-10-04。基线：`db17674`（已发布 0.2）。版本：0.3 / versionCode 4。

## 范围

新增 2048、贪吃蛇、打砖块、扫雷、推箱子、连连看、泡泡消除、蜘蛛纸牌，共九款离线游戏，不包含数独。保留俄罗斯方块规则、配色、回顶部、大按键与 0.2 原创音效。

蜘蛛纸牌为完整单花色模式：104 张牌，初始十列共 54 张、50 张库存分五轮发牌；没有空列才能发牌；K 到 A 完整序列自动收牌，八组获胜；最多撤销 64 步。牌列支持横向、纵向滚动。

推箱子包含八个渐进关卡，每关由搜索验证存在解；不是自动生成未知可解性的地图。扫雷有 8×8 / 10 雷和 10×12 / 20 雷两个难度。连连看无强制倒计时。贪吃蛇提供经典加速与固定速度。打砖块和泡泡消除支持过关后继续。
