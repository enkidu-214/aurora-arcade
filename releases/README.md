# 安装包

下载 [Release 0.1](https://github.com/enkidu-214/aurora-arcade/releases/tag/v0.1) 中的 `aurora-arcade-0.1.apk` 和 `SHA256SUMS`。

APK 不进入 Git 历史，本目录中的 `SHA256SUMS` 对应公开发布的版本化 APK。在两文件所在目录执行 `shasum -a 256 -c SHA256SUMS`（或 Linux 的 `sha256sum -c SHA256SUMS`）即可校验。

本机的 `aurora-arcade.apk` 是同一发布包的便捷副本；`aurora-arcade-debug.apk` 是开发调试包，签名不同，不能覆盖正式发布包。
